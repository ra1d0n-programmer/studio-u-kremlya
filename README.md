# 🏛️ Студия у Кремля · Studio by the Kremlin

Демо-проект для портфолио · Demo portfolio project

---

## 🇷🇺 Русский

**Студия у Кремля** — одностраничный демо-лендинг посуточной аренды студии с видом на Кремль.

- 🌍 **Мультиязычность:** 10 языков (RU, EN, ZH, ES, HI, AR, PT, FR, DE, JA), включая RTL-вёрстку для арабского.
- 📅 **Бронирование:** выбор дат, автоматический расчёт стоимости с учётом сезонов и стоимости уборки, проверка занятых дат.
- 📱 **Адаптив:** от 320px до широких экранов, поддержка safe-area (вырезы на iPhone), `prefers-reduced-motion`.
- 🎨 **Дизайн:** тёплая «бумажная» палитра, шрифты Cormorant Garamond + Inter.
- 🖼️ **Фото:** сгенерированы ИИ.

⚠️ Демо-проект для портфолио. Организация «Студия у Кремля» вымышлена, бронирование не осуществляется.

## 🇬🇧 English

**Studio by the Kremlin** — a single-page demo landing for a short-term rental studio with a Kremlin view.

- 🌍 **Multilingual:** 10 languages (RU, EN, ZH, ES, HI, AR, PT, FR, DE, JA), including RTL layout for Arabic.
- 📅 **Booking:** date selection, automatic price calculation with seasonal rates and cleaning fee, booked-date validation.
- 📱 **Responsive:** from 320px up to wide screens, safe-area support (iPhone notches), `prefers-reduced-motion`.
- 🎨 **Design:** warm paper palette, Cormorant Garamond + Inter fonts.
- 🖼️ **Photos:** AI-generated.

⚠️ Demo project for portfolio. “Studio by the Kremlin” is a fictional business, booking is disabled.
